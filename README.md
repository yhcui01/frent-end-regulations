# 阿里巴巴前端规约本地存档

本存档来自 [Alibaba f2e-spec](https://github.com/alibaba/f2e-spec)，下载日期为 2026-11-06。

## 本地浏览

在 macOS 中双击 `启动本地网页.command`，浏览器会自动打开完整的中文规约网站。终端窗口需保持打开，按 `Control + C` 停止服务。

也可以在本目录执行：

```sh
node local-server.mjs
```

默认地址：<http://127.0.0.1:4173/f2e-spec/zh/>

## 存档内容

- `f2e-spec/`：官网发布的静态网页和所有本地资源。
- `Markdown/`：左侧目录对应的 12 份中文原始文档，适合检索、备份和二次整理。
- `LICENSE`：原项目 Mozilla Public License 2.0 许可证。
